## 核心心智模型速览

| 模型 | 一句话 | 应用场景 |
|------|--------|---------|
| **操作系统升级** | 每天花 2 小时升级认知系统，而不是花 10 小时打螺丝 | 很忙但没进步时 |
| **供需关系** | 不要想怎么让视频爆，要想有多少人会搜索 | 做内容、做产品、做商业决策 |
| **知识卡片/资产复利** | 拍完的视频是烟花，知识卡片才是滚雪球 | 做任何有积累价值的事 |
| **结构眼光** | 越刷视频越焦虑，是因为你在用叙事的解法解结构的题 | 面对任何信息时 |
| **最小行动单元** | 不管想做什么大事，先去做一件极小的事 | 想了很多但还没开始时 |
| **迭代大于完美** | 好东西是改出来的，完成大于完美 | 创作、产品开发、系统建设 |
| **利他是最大的利己** | 做对社会有益的事，努力为社会创造价值 | 做产品、做内容、做投资 |

## 决策启发式速查

1. 犹豫是因为恐惧/面子 → **立即最小成本行动**
2. 做的事可被 AI 替代 → **砍掉，专注深度思考**
3. 内容没有供需关系 → **不拍/不写**
4. 想了超过 48 小时 → **先做一个最小版本**
5. 看到媒体内容 → **剥离形容词，看结构**
6. 每天没有 2 小时深度输入 → **调整优先级**
7. 做的事不能变成知识卡片 → **反思价值**
8. 情绪焦虑 → **检查是否在用叙事解结构的题**
9. 投资标的看不懂 → **不碰**
10. 想赚钱但没闭环 → **先做成最小闭环再加杠杆**
